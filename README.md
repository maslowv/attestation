# Атестація офіціантів · Китайський Привіт

- `index.html` — що бачать офіціанти (картка за карткою, з поясненнями).
- `admin.html` — адмінка за PIN: відповіді «за питаннями» / «за офіціантами», експорт CSV, редактор питань.
- `apps-script/Code.gs` — бекенд (Google Таблиця). Без нього сайт працює в демо-режимі (PIN 1234, дані лише в браузері).

## Підключення Google Таблиці (один раз, ~5 хв)
1. Створи порожню Google Таблицю → **Розширення → Apps Script**.
2. Встав вміст `apps-script/Code.gs`, **змін `ADMIN_PIN`** на свій.
3. **Розгорнути → Нове розгортання → Веб-застосунок**: виконувати від свого імені, доступ — **усі**. Скопіюй URL (закінчується на `/exec`).
4. Встав URL у `config.js` → `API_URL`.
5. Після будь-якої зміни `Code.gs` — «Керувати розгортаннями → редагувати → нова версія».

## Публікація на GitHub Pages
Залий папку `attestation` у репозиторій → **Settings → Pages → Deploy from branch**.
Офіціантам — посилання на `index.html`, собі — на `admin.html`.
